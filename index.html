  1. 在 Google Cloud 啟用 Google Drive API。

  3. 加入 GitHub Pages 網址為已授權 JavaScript 來源。

為什麼可以辨識名片？

OCR 會直接在本機瀏覽器處理照片，支援繁體中文與英文；影像不會因辨識而上傳到第三方 OCR 服務。完成校正並儲存後，才會寫入你的 Google Drive。
